Verses Across

A free scripture-study app: read texts side by side in many languages, in columns or verse by verse, on desktop or phone. It launched with 17 public-domain Bibles in 11 languages, including right-to-left Hebrew and Arabic, with more religions' texts coming.

Every text is imported by repeatable scripts from licence-verified public-domain sources. None of it is ever generated by AI. Verse numbering differences between traditions are mapped, so translations line up correctly or show an honest gap.

  • Next.js
  • TypeScript
  • Cloudflare Workers
  • Data import pipeline
  • Licensing review

How I work

Everything here is built with Claude Code.

Right model for each job

Within a project, each model takes the job it does best: Fable reviews, Opus plans, Sonnet builds, Haiku fetches. Bigger projects get built one phase at a time.

Use it myself

I run every version on my own desktop and phone, then go back with what's wrong or what's next.

Let real data catch up

Some projects can only go so far before they need real-world results. Those keep running and collecting, and the next step starts when there's enough to learn from.

Keep it running

Live on GitHub Pages, Cloudflare and Firebase, with tests, backups and alerts so things keep working when I'm not watching.
